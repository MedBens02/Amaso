# أدلة الاستعمال

دليل لكل دور في النظام. اقرأ الدليل الذي يخصّك، وليس غيره.

| الدور | الدليل | لمن |
|---|---|---|
| — | [البداية](getting-started.md) | **للجميع.** الدخول، رمز التحقق، كلمة السر. اقرأه أولاً. |
| مستخدم أعلى | [superuser.md](superuser.md) | من يدير الحسابات ويقرأ سجل النشاط |
| مدير النظام | [admin.md](admin.md) | مدير الجمعية |
| محاسب | [accountant.md](accountant.md) | من يمسك الدفاتر |
| أخصائي اجتماعي | [social-worker.md](social-worker.md) | من يتابع الأسر |
| مسؤول التعليم | [education-officer.md](education-officer.md) | من يتابع التمدرس والنقل |

لا تعرف دورك؟ افتح القائمة الجانبية: ما تراه فيها هو ما تملكه. أو اسأل
من يملك حساب **مستخدم أعلى** في الجمعية.
